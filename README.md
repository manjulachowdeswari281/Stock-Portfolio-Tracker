# Stock Portfolio Tracker

## About the Project
Stock Portfolio Tracker is a simple Python-based project that helps users manage and track their stock investments.

## Features
- Add stock names and quantities.
- Enter stock purchase prices.
- Calculate total investment value.
- Display stock portfolio details.
- View the total portfolio value.

## Technologies Used
- Python

## Purpose
This project was developed to understand Python basics, user input, calculations, and data management.

## Conclusion
This beginner-friendly project provides a simple way to maintain and track stock investment details using Python.
